# core/brand-token-derivation.md — 品牌定制 Token 推导指南

> **用途**：当用户指定品牌色 / 风格描述 / 参考图 / 竞品名称时，  
> 用本文件推导出完整的 CSS Token 体系，替代默认主题 Token。  
> **加载时机（Tier 3）**：用户有品牌定制需求时加载。  
> **前置**：必须先确定场景（scenes/*.md），再执行本文件的推导流程。

---

## 一、触发本文件的信号

| 用户说 | 触发动作 |
|--------|---------|
| "品牌色是 #XXXXXX" | 执行 §二 Token 推导 |

## 二、从品牌色推导完整 Token

### 2.1 推导规则

```
给定品牌主色 HEX，按以下规则推导：

──────────────────────────────────────────────────────
颜色 Token 名              推导规则
──────────────────────────────────────────────────────
--color-primary            = 品牌色原值（不修改）
--color-primary-dark       = 品牌色 明度 -10%~15%（Hover）
--color-primary-darker     = 品牌色 明度 -20%~25%（Active/Press）
--color-primary-light      = 品牌色 饱和度 -50%，明度 +30%（浅色 Tag/Badge 背景）
--color-primary-50         = 品牌色 饱和度 -70%，明度 +38%（极浅，页面区块/选中行）

--color-bg-page            = 品牌色 HSL 色相保留，饱和度 ≤5%，明度 ≥96%（≈近白）
--color-bg-card            = #FFFFFF（始终白色，不随品牌色变化）
--color-bg-hover           = 品牌色 -80% 饱和，+36% 明度（表格 hover 行）

--color-border             = 品牌色 HSL 色相保留，饱和度 10-15%，明度 85-88%
--color-divider            = 品牌色 HSL 色相保留，饱和度 5%，明度 92%

--color-text-primary       = 固定 #1A1A2E（深近黑，不随品牌色变化）
--color-text-body          = 固定 #4B4D63（深灰，不随品牌色变化）
--color-text-secondary     = 固定 #9395A8（浅灰，不随品牌色变化）
--color-text-disabled      = 固定 #C0C2CF

--color-positive           = 固定 #18A058（语义绿，不随品牌色变化）
--color-negative           = 固定 #F04848（语义红，不随品牌色变化）
--color-forecast           = 固定 #F0800A（语义橙，不随品牌色变化）

--shadow-sm                = 0 1px 4px rgba({品牌色RGB}, 0.06)
--shadow-md                = 0 4px 12px rgba({品牌色RGB}, 0.10)
──────────────────────────────────────────────────────
```

> **为什么文字色不随品牌变化**：文字的首要职责是可读性，固定的深灰色系在任何品牌背景下都能保证对比度 ≥ 4.5:1。品牌色影响的是"行动点和高亮点"，不是文字。

### 2.2 常见品牌色推导示例

```
品牌色 → --color-primary-light (Tag背景) → --color-bg-page (页面底色)

#2563F4 (数平蓝)  → #EBF1FE → #F4F7FE
#00B39B (医疗青绿)→ #E0F5F2 → #F0FBFA
#7C3AED (深紫)    → #F0EBFE → #F8F5FF
#DC2626 (企业红)  → #FDECEA → #FFF5F5
#D97706 (暖橙)    → #FEF3DC → #FFFBF0
#0EA5E9 (天蓝)    → #E0F3FE → #F0FAFF
#10B981 (翠绿)    → #E2F8F0 → #F0FCF7
```

### 2.3 完整推导模板（直接填写并输出）

```css
/* 品牌定制 Token — {品牌名} × {场景名} */
/* 生成时间：{date}，品牌主色：{hex} */

:root {
  /* ─── 品牌主色阶（从 {hex} 推导）──── */
  --color-primary:         {hex};
  --color-primary-dark:    {推导 Hover};
  --color-primary-darker:  {推导 Active};
  --color-primary-light:   {推导 浅色背景};
  --color-primary-50:      {推导 极浅背景};

  /* ─── 背景（品牌色相，近白）──────── */
  --color-bg-page:   {推导 页面底色};
  --color-bg-card:   #FFFFFF;
  --color-bg-hover:  {推导 hover底色};
  --color-bg-subtle: {推导 极浅信息带};

  /* ─── 边框与分隔（品牌色相，浅）──── */
  --color-border:  {推导 边框};
  --color-divider: {推导 分隔线};

  /* ─── 文字（固定，不随品牌变化）──── */
  --color-text-primary:   #1A1A2E;
  --color-text-body:      #4B4D63;
  --color-text-secondary: #9395A8;
  --color-text-disabled:  #C0C2CF;

  /* ─── 语义色（固定，不随品牌变化）── */
  --color-positive: #18A058;
  --color-negative: #F04848;
  --color-forecast: #F0800A;

  /* ─── 阴影（品牌色调）─────────────── */
  --shadow-sm: 0 1px 4px rgba({R},{G},{B}, 0.06);
  --shadow-md: 0 4px 12px rgba({R},{G},{B}, 0.10);
  --shadow-lg: 0 8px 32px rgba({R},{G},{B}, 0.12);
}
```

### 3.2 参考图解析流程

```
拿到参考截图时，按顺序提取以下信息：

1. 主色相（Hue）
   → 用色轮估算：冷（蓝紫） / 中（绿青） / 暖（橙红）

2. 明度风格
   → 整体亮 → 亮色主题（A/C/D/E）
   → 整体暗 → 暗色主题（B/F）

3. 圆角感
   → 卡片是否圆润？
   → 方 ≤ 4px / 中 6-8px / 圆 12-16px / 极圆 ≥ 20px

4. 信息密度
   → 卡片内部内容多不多？
   → 稀疏（Landing Page 感）/ 适中 / 密集（Tool/Dashboard 感）

5. 装饰量
   → 有没有光晕 / 渐变 / 插图 / 图片？
   → 有大量装饰 → Landing Page / E-Bold
   → 几乎无装饰 → D-Minimal / Tool App

6. 字重感
   → 标题是粗黑吗？数字是大号吗？
   → 粗重 → E-Bold Bento
   → 轻细 → D-Minimal / C-Editorial
```

```

科技/严谨         4-6px (小)     shadow-sm 或无     紧凑        600-700
专业/大厂         6-8px (中)     shadow-sm          适中        500-600
温暖/亲切         10-14px (大)   shadow-md (暖色)   宽松        400-500
简约/高端         4-6px (小)     无/极弱 1px边框    极宽松      300-400
活泼/年轻         12-16px (大)   shadow-md          宽松        600
```

```
感受关键词        背景色倾向                  装饰量
────────────────────────────────────────────────────
科技/深邃         深色（考虑 B/F 主题）        低：几何图形
温暖/自然         暖白色（偏黄/橙调）          中：插图/图标

```

## 五、图表配色的品牌定制规则

```javascript
/**
 * 品牌化图表配色序列推导规则
 *
 * 第 0 色 = 品牌主色（与 --color-primary 一致）
 * 第 1 色 = 品牌主色色相 +120°（色轮三等分第一点）
 * 第 2 色 = 品牌主色色相 +210°（色轮三等分第二点 + 微调）
 * 第 3 色 = 品牌主色色相 +60°
 * 第 4-8 色 = 继续按色相均匀分布，饱和度适度降低
 *
 * 原则：
 * - 第 0 色必须与品牌主色一致
 * - 所有系列色不得与 --color-positive(绿)/--color-negative(红) 完全重叠
 * - 相邻系列色的色相差 ≥ 30°（确保并排时可区分）
 */

// 示例：品牌色 #7C3AED（深紫）的图表色序
const CUSTOM_CHART_PALETTE = [
  '#7C3AED',  // 0 品牌紫（主色）
  '#00C4A0',  // 1 +120° 青绿
  '#F5A623',  // 2 +210° 琥珀橙
  '#A855F7',  // 3 浅紫（同色相更亮）
  '#3B82F6',  // 4 蓝
  '#F472B6',  // 5 粉
  '#34D399',  // 6 浅绿
  '#94A3B8',  // 7 灰蓝（低优先级）
];
```
